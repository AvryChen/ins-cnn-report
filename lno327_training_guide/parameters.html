模型到底在反推哪些参数

当前目标不是随便预测几个数，而是预测 Sunny 模型里的五个物理参数。它们共同决定 spin-wave spectrum 的峰位置、能量尺度、强度分布和各向异性细节。

输出顺序固定

[SJc, SJ1a, SJ1b, SJ2, SA]

1. 五个物理参数

训练数据里每个样本都有一组真实参数。Sunny 用这组参数生成谱图；CNN 反过来根据谱图预测这组参数。下面这张表是目前代码里的解释口径。

参数 物理含义 在模型里的作用 为什么难/有用
SJc 双层内上下 Ni 之间的 c 方向/层间交换。 代码里对应 Bond(1,2,[0,0,0])。 主要影响层间耦合相关的色散和 L 依赖；只看固定路径时信息容易被压缩。
SJ1a 面内最近邻 a/H 方向交换。 代码里对应 Bond(atom,atom,[1,0,0])。 和 H 方向峰形、色散斜率相关，通常比 SJc 更容易从图上读出来。
SJ1b 面内最近邻 b/K 方向交换。 代码里对应 Bond(atom,atom,[0,1,0])。 和 K 方向响应相关；与 SJ1a 的差别体现面内各向异性。
SJ2 面内对角次近邻交换。 代码里同时作用于 [1,1,0] 和 [1,-1,0]。 会改变更细的弯曲、交叉和弱峰结构；CNN 比展平模型更适合抓这种局部图像特征。
SA 单离子各向异性。 代码中是 onsite coupling SA*S[1]^2，当前采样范围为负值。 数值尺度很小，不能只看绝对 MAE；需要用 range-normalized MAE 评估。
参数名里的 S 表示当前代码按有效的 S*J 或 S*A 组合量处理。机器学习模型并不直接理解物理，只学习这些参数变化如何改变谱图。

2. narrow / wide 范围

narrow 和 wide 的区别不是模型结构，而是训练数据里的参数采样范围。范围越大，模型要覆盖的谱图变化越多，反演也越难。

参数 当前 wide preset 解释
SJc 25 到 55 跨度大，层间交换变化显著；也是目前较难压低误差的参数之一。
SJ1a 0.2 到 6.0 面内 a 方向最近邻交换。
SJ1b 0.5 到 8.0 面内 b 方向最近邻交换。
SJ2 1.0 到 9.0 次近邻交换，往往需要靠更细的峰形和弱峰结构约束。
SA -0.20 到 -0.001 量级小，因此必须归一化看误差。

早期 narrow 结果更像“证明方法能跑通”。wide 和 pure-wide 更接近真正想做的反演：给一个更宽的参数空间，让模型在没见过的验证/测试样本上仍然能给出可信参数。

3. 这些参数是不是独立的

从采样程序角度看，训练集会把这五个量作为独立坐标去抽样；从物理谱图角度看，它们的影响不是独立可分的。也就是说，两个不同参数可能改变同一条色散线，或者一个参数的影响会被另一个参数部分抵消。

所以反向拟合不是简单读数。模型遇到的是一个多参数耦合问题：同一张谱图可能同时含有 SJc、SJ1a、SJ1b、SJ2、SA 的混合影响。

这也是为什么我们要关注 4D 和弱峰。强峰区域可能主要受某几个参数支配，导致另外一些参数不敏感；弱峰、肩峰、L 依赖和不同能量切片可能提供额外约束。

4. 训练超参数和物理参数不是一回事

报告里还会出现 batch、hidden、embedding、epoch、learning rate 这类词。这些不是物理模型参数，而是训练 CNN 时的工程设置。

名称 当前常用值 人话解释
batch size 128 on RTX 4080S AMP 一次喂给 GPU 的样本数。越大通常越快，但显存会涨。
hidden 32 CNN 内部通道数的基础宽度。越大模型容量越高，也更吃显存。
embedding 64 每个分支最终压缩出的特征向量长度。
epochs 280 formal scratch run 完整扫过训练集的轮数。早停会用验证集决定是否提前停止。
learning rate 1e-3 scratch / 2e-3 等 head-only 每次更新参数的步长。过大容易震荡，过小收敛慢。
AMP float16 + GradScaler 混合精度训练。主要为加速和省显存，但必须检查精度是否变差。
