1. 训练循环

每个样本都有真实参数。模型根据谱图输出五个预测值，代码先在 0 到 1 的归一化参数空间里算误差，然后通过反向传播更新 CNN 权重。

1
读取一个 batch

例如 batch=128，就是一次从训练集拿 128 个样本进 GPU。

2
前向预测

Fig.3 和 4D 经过 CNN，输出五个 0 到 1 之间的归一化参数。

3
计算 loss

主 loss 是归一化参数的 MSE；gated/residual 模型可以加 auxiliary loss。

4
更新权重并验证

每个 epoch 后看 validation loss；保存验证集最好的 checkpoint。

validation 用来选模型和 ensemble 权重；test 只用于最终报告。不要用 test 来反复调参数，否则结果会虚高。

2. 指标怎么读

最重要的指标是 mean range-normalized MAE。它先算每个参数的 MAE，再除以该参数的采样范围，最后对五个参数平均。

range_MAE(param) = MAE(param) / (param_max - param_min) mean_range_MAE = mean(range_MAE over SJc, SJ1a, SJ1b, SJ2, SA)

为什么要这样？因为 SA 的绝对数值很小，SJc 的绝对数值很大。只看原始 MAE 会让不同参数不可比。

指标 含义 怎么判断
train loss 训练集上的归一化 MSE。 下降说明模型在学习；太低但 val 不降可能是过拟合。
val loss 验证集上的归一化 MSE。 决定保存哪个 epoch 的模型。
test mean range MAE 测试集上五个参数的平均相对 MAE。 越低越好，是当前最重要的汇报数字。
per-parameter MAE/range 每个参数单独的相对误差。 用来判断 SJc、SA 等难参数是否拖后腿。
R2 预测解释方差的比例。 接近 1 好；但在小 test set 上需结合 MAE 看。

3. AMP 与 batch

AMP 是 automatic mixed precision。简单说，它让大部分 GPU 运算用 float16 跑，同时用 GradScaler 避免梯度下溢。目的主要是加速和省显存，但必须确认精度不变差。

配置 n1024 AMP sweep 结果 结论
gated4d, hidden=32, embedding=64, batch=128 OK，峰值约 27391 MB，约 29.2 samples/s。 当前正式训练配置。
residual4d, hidden=32, embedding=64, batch=128 OK，峰值约 27391 MB，约 27.8 samples/s。 下一条正式对照配置。
batch=160 或 192 OOM。 4080S 这份 4D 数据上不能简单把 batch 再加大。
hidden=48, embedding=96 OOM。 更大模型不是当前最稳路线；需要降低分辨率、做梯度累积或改结构。
显存大不等于应该盲目放大模型。当前 4D 输入本身很大，batch=128 已经接近稳定上限。下一步更合理的是 AMP 稳定性验证、梯度累积、数据加载/CPU 生成加速和模型结构对照。

4. 当前正式 run

当前云端正式训练使用 pure-wide n1024 数据集，目标是验证 AMP float16 在 4080S 上是否能保持精度并提高吞吐。命令形态如下：

python scripts/lno327_run_cnn_task.py \
  --data data/lno327_inverse_4d_wide_extra_augtrain_n1024_q160_e180_h81_k121_l5.h5 \
  --out runs/lno327_inverse_cnn_weakpeak_n512/gated4d_wide_extra_augtrain_scratch_e280_aux015_seed20260705_ampfp16_b128 \
  --mode gated4d \
  --epochs 280 \
  --batch-size 128 \
  --hidden 32 \
  --embedding 64 \
  --lr 1e-3 \
  --weight-decay 1e-3 \
  --aux-weight 0.15 \
  --seed 20260705 \
  --device cuda \
  --patience 80 \
  --amp \
  --amp-dtype float16

已知对照：同 seed 的 FP32 gated4d 从头训练曾完成，best epoch 为 278，test mean range MAE 为 4.5813%。这不是历史最好结果，但可作为 AMP 是否变差的直接对照。

5. 下一步策略

现在的判断标准应该按顺序来，不要只追求“更大”。

  1. 等 gated4d AMP run 完成，记录 wall time、best epoch、test mean range MAE、每个参数误差和 GPU trace。
  2. 如果 AMP 精度不劣于 FP32，再跑 residual4d AMP，同样记录完整报告。
  3. 做 gated4d + residual4d ensemble，比较 global ensemble 和 per-parameter ensemble。
  4. 如果 batch 128 已经稳定但还想提高等效 batch，可以试梯度累积，而不是直接把 batch 推到 OOM。
  5. 如果要继续提升物理反演能力，优先扩 pure-wide 样本和更合理的 high-sensitivity 区域采样，再考虑更大网络。
当前最重要的报告内容应该包括：训练耗时、GPU 峰值显存、samples/s、best epoch、test 总误差、五个参数分别的误差、和上一条 run 的差异。只报一个总 MAE 不够。
