CNN 在这个项目里到底做了什么

CNN 不是魔法。它做的是：把谱图当成图像，先提取局部峰形和强度结构，再把这些结构压缩成特征向量，最后用全连接层输出五个归一化参数。

1. 先用人话解释 CNN

假设你在看一张 INS 谱图。你不会只读单个像素，而会看一小片区域：这里是不是有峰、峰有没有变宽、曲线有没有弯、弱峰是不是被强峰遮住。CNN 做的事情和这个很像。

1
小窗口扫描图像

卷积核每次看局部区域，学习“峰”“边缘”“弯曲”“局部强度变化”这类图案。

2
重复多层

第一层看局部亮点，后面几层把局部亮点组合成更大的色散形状。

3
压缩成特征向量

最后把整张图压成几十维的 embedding，代表这张谱图的关键信息。

4
输出参数

预测头把 embedding 映射到五个参数的归一化值。

这就是为什么 CNN 比普通 MLP 更适合当前任务：它保留了谱图的空间结构，而不是一开始就把图打散成一串数字。

2. weak-peak 预处理

INS 图里强峰很容易支配损失和视觉效果。我们真正关心的弱峰、肩峰、细小形状变化，可能被强峰压住。所以输入 CNN 前会做 weak-peak transform：

scale = 每个样本自己的 99.5% 强度分位数 x = clip(x / scale, 0, 1) x = x ^ gamma, 当前 gamma = 0.5

这个操作不是简单取 log。它的意思是：先按每张图自己的高分位强度归一化，再用平方根把弱信号抬起来。强峰仍然存在，但不会完全遮住弱峰。

这一步会改变模型看到的强度比例，所以必须在训练、验证、测试、paper reference 预测时保持完全一致。当前代码正是这样做的。

3. 基础 CNN encoder 结构

当前基础 encoder 不复杂，重点是稳。它由三层卷积和两个池化组成，最后用全局平均池化压成 embedding。

阶段 结构 作用
卷积 1 Conv2d(in_channels, hidden, kernel=5) + GroupNorm + GELU 看较大的局部窗口，提取初级峰形。
下采样 1 MaxPool2d(2) 缩小图像尺寸，提高后续感受野。
卷积 2 Conv2d(hidden, hidden*2, kernel=3) + GroupNorm + GELU 组合更复杂的局部结构。
下采样 2 MaxPool2d(2) 进一步压缩空间尺寸。
卷积 3 Conv2d(hidden*2, hidden*2, kernel=3) + GELU 形成更高层的谱图特征。
全局池化 AdaptiveAvgPool2d(1,1) 把不同位置的信息汇总成一个向量。
embedding Linear(hidden*2, embedding) + GELU 得到固定长度的谱图特征。

当前常用设置是 hidden=32、embedding=64。在 RTX 4080S 上，试过更大的 hidden=48、embedding=96，但实际 4D n1024 sweep 会 OOM，所以正式训练仍用 32/64。

4. 当前几类模型结构

代码里有多个 mode。它们的区别主要在于：看不看 Fig.3，看不看 4D，以及如何融合二者。

mode 输入 结构 一句话评价
fig3 Fig.3 路径谱 一个 Fig.3 CNN encoder + prediction head。 便宜、稳定，是判断 4D 是否有用的底线。
fig4d 4D volume 转成 50 通道 H-K 图 一个 4D CNN encoder + prediction head。 只看 4D，不看 Fig.3；可以做对照，但不是当前最稳主线。
combined4d Fig.3 + 4D 两个 encoder 的 embedding 拼接后预测。 直接拼接，简单但容易让 4D 分支干扰 Fig.3。
gated4d Fig.3 + 4D Fig.3 embedding 加上 gate 控制后的 4D embedding。 Fig.3 是主证据，4D 通过 gate 补充。
param_gated4d Fig.3 + 4D 每个参数各有一个 gate，控制 4D residual 加多少。 更细，但参数更多；泛化不一定更稳。
residual4d Fig.3 + 4D 先用 Fig.3 预测，再让 4D 学一个受限 correction。 当前很重要，因为它限制 4D 不要推翻 Fig.3 主证据。

5. 为什么 residual4d 值得重视

直接把 Fig.3 和 4D 拼起来并不一定最好。4D 数据量大、通道多，模型可能在训练集上学到噪声或偶然模式，反而损害测试集。residual4d 的设计更保守：

Fig.3 logits = Fig.3 分支的基础预测 correction logits = 4D 分支根据联合特征给出的修正 fused logits = Fig.3 logits + residual_scale * gate * correction logits

这里 residual_scale 默认是 0.5，gate 初始也偏小。也就是说，模型一开始更相信 Fig.3；只有当 4D 分支真的能降低验证集误差时，它才逐渐加大修正。

gated4d

更像“Fig.3 特征 + 4D 特征”。适合从头训练，能学到比较完整的融合表示。

residual4d

更像“Fig.3 预测 + 4D 修正”。适合做 head-only 微调和 ensemble，也更容易解释。

当前实践结果说明：单模型不一定总是 residual4d 最强，但 gated4d + residual4d ensemble 往往比任一单模型更好，因为两者错误模式不完全一样。
